# HACKERS – Android starter

## ما الذي يعمل الآن؟
- واجهة داكنة بالأسود والأخضر النيون.
- إدخال العمر واختيار النظام الدراسي.
- اختيار الصف الدراسي.
- اختيار مسار البكالوريا عند اختيار البكالوريا المصرية.
- اختيار المادة.
- إدخال السؤال نصياً.
- مكان مبدئي لعرض الإجابة النهائية فقط وزر نسخ.

## ما الذي لم يُربط بعد؟
زر «حل السؤال» يعرض رسالة تجريبية فقط. يلزم بناء خادم آمن وربطه بمزود ذكاء اصطناعي قبل أن يحل الأسئلة فعلياً. لا تضع مفتاح API داخل تطبيق أندرويد؛ يجب حفظه على الخادم.

## فتح المشروع
1. نزّل Android Studio على الكمبيوتر.
2. فك ضغط الملف.
3. افتح مجلد HACKERS_Android_Starter في Android Studio.
4. انتظر Gradle Sync.
5. شغّل التطبيق على هاتف أندرويد أو المحاكي.

هذه ملفات بداية للمشروع وليست APK جاهزاً.
